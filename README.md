# coloratum

> [!CAUTION]
>
> 请在运行本软件前**务必**检查 SHA256 签名，以免第三方恶意投毒。本软件开源免费，且全程离线运行，**绝不会**以任何方式索取费用、打开第三方网站或引导联网操作

> [!WARNING]
>
> 本软件及其补丁仅供学习使用，如有能力，请支持正版

coloratum 是一个适用于 SPSS 32.0.0.0 的认证绕过补丁，它可以将几个 Jar 替换进 SPSS 安装目录来改变原程序的认证行为

> [!NOTE]
>
> 本补丁可能导致程序运行不稳定，如出现这种情况，请恢复备份或将原软件卸载重装；**也建议您在使用patch后的软件时勤加备份自己宝贵的数据集**

## 下载和使用

您可以前往 [Release](https://github.com/nofyso/coloratum/releases) 页面找到程序的二进制构建，下载它后执行即可

程序可能无法找到 SPSS 的安装目录，届时您需要手动提供安装目录来完成补丁应用

## 工作原理

补丁修改了原先软件的认证逻辑和许可证检查逻辑，删除了联网检查功能并硬编码了许可证状态，到期日期等信息，来达到绕过认证机制来正常使用软件的目的

## 额外信息

您可以反编译 src 文件夹下的 Jar 补丁文件、阅读 coloratum 的源码来确认本补丁的安全状况，Github Release 上的二进制可执行文件通常是安全的，如果您仍有顾虑，可以手动将 Jar 文件复制进 SPSS 安装文件夹覆盖原有文件，或自行安装 Rust 工具链来编译 coloratum
